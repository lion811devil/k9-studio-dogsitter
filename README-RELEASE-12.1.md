# Release 12.1 — Sincronizzazione acconti, notifiche e log

Questa release corregge esclusivamente il collegamento economico tra un preventivo già trasformato e il relativo servizio.

- Il preventivo viene trasformato in servizio una sola volta.
- Modificando successivamente acconto, saldo, modalità o totale del preventivo, il servizio collegato viene aggiornato automaticamente.
- Il PDF Cliente e il PDF Interno generati dopo l'aggiornamento leggono i valori aggiornati.
- Datore di lavoro e Vice ricevono una notifica personale; il dipendente non riceve dati economici del cliente.
- Il Registro attività mostra il preventivo e l'evento di sincronizzazione economica.
- Nessun documento viene inviato automaticamente.
