# Release 12.5.2 — Calendario personale giornaliero

- Il pulsante **Collega a calendario** compare esclusivamente in **I miei servizi**.
- È disponibile per Dipendente, Super Admin e Vice amministratore.
- Il Dipendente può collegare solo i servizi assegnati al proprio account.
- Super Admin e Vice possono collegare i servizi visualizzati nella propria sezione.
- Per ogni giorno compreso nei periodi viene creato un evento separato.
- Il titolo contiene esclusivamente: `Tipo servizio • Cliente • Cane`.
- Non vengono inseriti indirizzo, telefono, note, compensi o altri dati.
- Più servizi nelle stesse date generano eventi distinti grazie a UID separati per servizio e giorno.
