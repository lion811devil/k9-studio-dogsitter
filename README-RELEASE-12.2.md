# Release 12.2 — CRM Cliente, Log e Notifiche

Correzione esclusivamente frontend. Non richiede migrazioni SQL.

## Modifiche
- CRM Cliente con riepilogo, contatori per stato, documenti e comunicazioni.
- Situazione economica separata in preventivi, servizi, incassato, acconti e residuo.
- Pulsante cliente “Archivia” al posto di “Elimina”.
- Azione rapida “Nuovo servizio”.
- Registro attività leggibile, senza JSON, UUID, campi null o nomi tecnici.
- Notifiche sintetiche e orientate all’azione.
