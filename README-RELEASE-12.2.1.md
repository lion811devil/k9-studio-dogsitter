# Release 12.2.1 — Correzione Log e Notifiche

Correzione esclusiva della leggibilità del Registro attività e dell'affidabilità delle notifiche interne.

## Obbligatorio
Eseguire una volta `supabase/migrations/release-12.2.1-log-notifiche.sql` nel SQL Editor di Supabase.

## Verifica
Aprire **Notifiche** e premere **Verifica notifiche**. Deve comparire una nuova notifica di prova.
